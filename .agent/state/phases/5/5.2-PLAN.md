# Plan 5.2: Sidebar Baseline Verification

## Objective
Establish a strict verification baseline for the Sidebar component before any modifications. This ensures that the upcoming additions (Map Toggle, Calendar Link) do not accidentally alter the existing layout, button count, or inline styles/template structure, which has caused regressions in the past.

## Context
- src/app/components/sidebar/sidebar.component.spec.ts
- src/app/components/sidebar/sidebar.component.ts
