## Overview

Velopitt is an Angular v20+ web application focused on visualizing cycling segments and data in Pittsburgh. It utilizes Mapbox GL JS for interactive mapping and visualizes segment data (gradients, elevation) using charts. The architecture follows a modern Angular signal-based reactive flow, with a central `AppComponent` orchestrating state between the map, sidebar, and overlays.

## Data Flow

1. **Initialization**: `SegmentService` loads static JSON data. `AppMapComponent` initializes Mapbox.
2. **Interaction**: User clicks a segment on the map → `AppMapComponent` emits event.
3. **State Update**: `AppComponent` receives event, updates `selectedSegment` signal.
4. **Reaction**: `SegmentOverlayComponent` (if visible) reads data from `SegmentService` based on ID. `AppMapComponent` updates styles (highlighting) via effects.
